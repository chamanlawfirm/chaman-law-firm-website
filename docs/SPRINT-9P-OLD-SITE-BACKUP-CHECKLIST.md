# Sprint 9P Old Site Backup Checklist

Date: 2026-06-27

Purpose: confirm the old Chaman Law Firm website can be restored before any domain cutover.

Production launch remains No-Go until this checklist is completed and the backup location is confirmed.

## Required Backups

- [ ] Full WordPress backup exported.
- [ ] WordPress database backup exported.
- [ ] `wp-content/uploads` backup exported.
- [ ] Theme backup exported where available.
- [ ] Plugin backup exported where available.
- [ ] RankMath SEO export completed.
- [ ] Redirect export completed where available.
- [ ] Current sitemap export saved.
- [ ] Current `robots.txt` copy saved.
- [ ] Current DNS records screenshot or export saved.
- [ ] Hostinger/domain panel screenshot or export saved.
- [ ] Old website homepage screenshot saved.
- [ ] Old blog sitemap snapshot saved.
- [ ] Top legacy URLs backup saved.
- [ ] Backup stored outside the live hosting account.
- [ ] Backup restore owner identified.
- [ ] Backup restore method understood.
- [ ] Backup date and time recorded.

## Backup Storage Rule

Store at least one backup copy outside the live hosting account. Acceptable locations include a secured local drive, approved cloud storage, or a separate backup account controlled by the firm.

## Launch Gate

If any mandatory backup item is missing, do not proceed with Sprint 10A domain cutover.
