## Warnings To Record

- Crawled - currently not indexed.
- Discovered - currently not indexed.
- Duplicate without user-selected canonical.
- Alternate page with proper canonical.
- Soft 404.
- Blocked by robots.txt.
- Redirect error.
- Server error or timeout.
- Page fetch failed.
- Mobile usability warnings.
- Video/image indexing warnings.
- Meta description or title rewrite signals.

## Classification

- **Monitor only**: page is discoverable, canonical is correct, no server issue, but indexing is pending.
- **Fix content**: thin body, weak metadata, repeated image, unclear title, or possible legal-risk wording.
- **Fix technical**: sitemap missing, redirect error, canonical mismatch, robots issue, or 5xx/timeout.
- **Do not inspect**: hidden drafts, unapproved legacy URLs, or URLs that intentionally remain 404 until restored.
